# Image-Encryption-Decryption
Image Encryption and Description 
This project demonstrates a secure image encryption and decryption system designed to protect digital images from unauthorized access. The main goal of the project is to convert an original image into an unreadable encrypted form using a secret key and then restore it back to its original state through a decryption process.

The encryption technique applies pixel-level transformations and mathematical operations to ensure data confidentiality while maintaining image integrity. Only users with the correct key can successfully decrypt and view the original image.

🚀 Features

Secure image encryption using a secret key

Accurate image decryption with zero data loss

Supports common image formats (PNG, JPG, JPEG)

Fast processing with minimal quality degradation

Simple and beginner-friendly implementation

🛠️ Technologies Used

Programming Language: Python

Libraries: NumPy, OpenCV, Pillow

Encryption Logic: Pixel manipulation & XOR-based operations

📌 Use Cases

Secure image sharing

Privacy protection in digital media

Learning cryptography concepts through images
